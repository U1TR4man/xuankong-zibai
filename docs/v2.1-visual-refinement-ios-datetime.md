# 2. P0 — 修正 iOS 日期輸入 border / focus 走位

## 2.1 重現情況

目前操作：

```text
主畫面
→ 點日期時間
→ 開「選擇時間」 Bottom Sheet
→ 點「日期」
→ iOS native calendar 彈出
```

實機可見：

- 日期 input 本身有既有 border
- global `:focus-visible` 再畫一層朱砂 outline
- iOS native `<input type="date">` 有自己的內部 rendering / intrinsic box
- native picker 打開時，focus ring 與 input 的視覺框看起來錯位
- 截圖中可見紅色 focus border 不再乾淨貼合 input 外框
- 有「border 走位／雙框／超出容器」的感覺

這是 **UI rendering bug**，不是玄空時間計算 bug。

iOS 彈出的深色 calendar 是系統 native picker；**不要嘗試用 CSS 去重新 skin 系統 calendar**。

我們只需要保證 App 自己的日期／時間輸入框穩定。

---

## 2.2 目前相關程式

`src/ui/TimePickerSheet.ts`

目前大意：

```ts
const dateInput = el('input', {
  class: 'sheet-field',
  type: 'date',
  ...
});

const timeInput = el('input', {
  class: 'sheet-field',
  type: 'time',
  ...
});
```

`src/styles.css`

目前：

```css
.sheet-field {
  width: 100%;
  min-height: 48px;
  padding: ...;
  background: ...;
  border: 1px solid ...;
  border-radius: ...;
}

:focus-visible {
  outline: 2px solid var(--focus);
  outline-offset: 2px;
}
```

**問題點：**

視覺外框、padding、背景、focus outline 全都直接掛在 native date/time input 上。

這在 desktop text input 通常沒問題，但 iOS date/time control 有自己的 native box model / appearance。

# 3. 正確修法：Visual Shell + Borderless Native Input

## 3.1 不要再讓 native input 自己擁有外框

改成：

```text
label
└── visual shell
    └── native input
```

建議 DOM：

```html
<label class="sheet-field-group">
  <span class="sheet-field-label">日期</span>

  <span class="sheet-input-shell">
    <input
      class="sheet-native-input"
      type="date"
    />
  </span>
</label>
```

時間同樣：

```html
<span class="sheet-input-shell">
  <input
    class="sheet-native-input"
    type="time"
  />
</span>
```

---

## 3.2 Shell 負責所有視覺

```css
.sheet-input-shell {
  width: 100%;
  min-width: 0;
  min-height: 48px;

  display: flex;
  align-items: center;

  padding: var(--s2) var(--s3);

  background: var(--paper);
  border: 1px solid var(--line-strong);
  border-radius: var(--radius-sm);
}
```

Native input：

```css
.sheet-native-input {
  display: block;

  width: 100%;
  min-width: 0;
  max-width: 100%;

  padding: 0;
  margin: 0;

  border: 0;
  outline: 0;
  background: transparent;

  color: var(--ink);
  font: inherit;
  font-variant-numeric: tabular-nums;
}
```

注意：

```text
不要在 full-width native date/time input 本身加 horizontal padding。
```

padding 只放在 shell。

---

## 3.3 Focus state 放在 shell

不能直接把 accessibility focus 拿走。

改：

```css
.sheet-input-shell:focus-within {
  outline: 2px solid var(--focus);
  outline-offset: 2px;
}
```

並對這兩種 native input 關閉 global focus outline：

```css
.sheet-native-input:focus-visible {
  outline: none;
}
```

或用更窄 selector：

```css
.sheet-input-shell > input[type="date"]:focus-visible,
.sheet-input-shell > input[type="time"]:focus-visible {
  outline: none;
}
```

**只能在 shell 已提供可見 focus indicator 的前提下這樣做。**

不要全站：

```css
input:focus {
  outline: none;
}
```

---

## 3.4 保留 native picker 行為

不要：

```css
appearance: none;
-webkit-appearance: none;
```

除非實機確認不會破壞 iOS calendar/time picker。

原則：

> 我們只接管 input 外層 frame，不接管 native picker 本身。

---

## 3.5 需要檢查 calendar indicator

iOS / Safari / Chrome 對 date/time input 的 indicator 行為不同。

不要硬藏：

```css
::-webkit-calendar-picker-indicator {
  display: none;
}
```

除非確定整個 input 都仍可 tap 開 picker。

V2.1 優先保留 native usability。

# 5. P1 — 預載自帶 Display Serif

目前 `--font-display` 依賴：

```css

'STSong',
'Noto Serif TC',
```

- iPhone 上字形與設計 mockup 有落差

---

## 5.1 Font scope

自帶 Serif 只用在：

```text
玄空紫白
子時／午時等主標題
九星名稱
中宮主字
年／月／日／時／刻層級文字

```

普通 UI：

```text
日期時間
按鈕
設定
細節說明
節氣 meta
方位

```

繼續：

```css
-apple-system,
BlinkMacSystemFont,
'PingFang TC',
...
```

---

## 5.2 Font loading

使用本地 WOFF2。

例如：

```text
public/fonts/
  zibai-serif-medium.woff2
  zibai-serif-semibold.woff2
```

若可行，做繁中所需 glyph subset，避免整套 CJK font 過大。

不要 runtime Google Fonts。

`index.html`：

```html
<link
  rel="preload"
  href="/xuankong-zibai/fonts/zibai-serif-medium.woff2"
  as="font"
  type="font/woff2"
  crossorigin
>
```

注意 GitHub Pages base path。

**不要硬寫會在 `/xuankong-zibai/` deployment 失效的 asset path。**

優先使用 Vite base / `%BASE_URL%` 可兼容的方式。
