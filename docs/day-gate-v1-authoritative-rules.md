# Day Gate V1 authoritative rules

> 狀態：2026-08-10 封版供 V1 實作。這一輪只處理「日干 × 月令」；四柱沖合、月破、日時沖、時扶日與日干祿時仍屬下一階段。

## 輸入與研究邊界

- 原始規劃：`紫白擇吉_下一階段研究規劃_DayGate優先.md`
- 原始檔 SHA-256：`e45f14022585a4f3fececde176ab178532aba28829492fda99cbb8aecfac6c3e`
- 月柱繼續取專案既有節氣月，精確到節氣交接時刻；不改 UTC+8、節氣表或四柱 Engine。
- V1 不用納音、不建神煞庫、不把所有規則合成數值分數。
- Day Gate 只產生 `pass / mixed / caution`，不 hard reject，也不改八方方向 verdict 或排序。

## 六個研究問題的定案

### 1. 旺相休囚死原文與算法

《多能鄙事》卷六〈旺相休囚死例〉直接保存五季表；《五行精紀》卷七又說「五行當時者旺，所生者相，所克者死，生我者休，克我者囚」。換成「月令司氣」與「日干五行」的 deterministic 規則如下：

| 日干與月令司氣的關係 | 狀態 |
|---|---|
| 同我 | 旺 |
| 月令生我 | 相 |
| 我生月令 | 休 |
| 我剋月令 | 囚 |
| 月令剋我 | 死 |

十干五行固定為：甲乙木、丙丁火、戊己土、庚辛金、壬癸水。

### 2. 月令取節氣月，不取公曆月或農曆朔望月

《欽定續通志》所載十二月建以節氣開月：立春建寅、驚蟄建卯、清明建辰，依次至小寒建丑。V1 沿用現有 `getSolarMonthByJieqi()` 與 `buildTemporalPillars()`；節氣正交時才換月支。

### 3. 土旺不是整個辰戌丑未月

《御定星曆考原》卷一引《神樞經》與曆例：土在四立之前各旺十八日，全年合七十二日。《三命通會》亦保存「清明後十二日，用戊土十八日；夏秋冬同」的切分線索。

V1 採下列可重跑規則：

1. 先找下一個立春、立夏、立秋或立冬的精確時刻。
2. 距該四立不足或等於十八個整日，司令五行取土。
3. 其餘時間按四季主氣：春木、夏火、秋金、冬水。
4. 月支仍是當下節氣月支；只另存 Day Gate 的司令五行，不改既有九星月令矩陣。

### 4. 旺相對 V1 的 veto 強度

《造命宗鏡集》卷六說「用日宜擇旺相，忌休囚」，證明日課旺衰不是普通加分項；但同卷亦要求日課與四柱成格，不能只憑單一月令狀態決定全課。

因此 V1 定案：

| 狀態 | Day Gate | V1 行為 |
|---|---|---|
| 旺、相 | pass | 顯示通過 |
| 休 | mixed | 顯示偏弱 |
| 囚、死 | caution | 顯示慎看 |

`caution` 不是 `reject`。在四柱生扶、沖合與 Hour Gate 未完成前，不宣稱單憑囚死即可否決整個時段。

### 5. 休囚可否因生扶再用

可以。《造命宗鏡集》明說用時可幫日干、幫四柱；小修「只幫扶日主，使日不休囚」，又舉日干不旺可用祿時使旺。這是直接的操作文字，所以 V1 必須保留未來由 Hour Gate 改善弱日的空間。

本輪只記錄這個可恢復邊界，不先實作時扶日或祿時。

### 6. 與四柱干支沖合的優先順序

同卷先列時沖月令、沖歲君為「大凶，決不可用」，並列時支沖日支的破時為大凶；另一方面，時與日干支同類或與日三合才作幫扶。這表示後續規則順序應是：

```text
先檢查高優先沖破
→ 再判四柱能否成格／生扶
→ 最後以時辰扶日與祿時細選
```

V1 不把這些未實作條件假裝成已評估；UI 明示「四柱沖合、時辰扶日尚未納入」。

## V1 程式契約

```ts
interface DayGate {
  dayStem: Stem;
  dayElement: Element;
  monthBranch: Branch;
  monthElement: Element;
  monthCommandRule: "season_main" | "earth_last_18_days";
  seasonalState: "wang" | "xiang" | "xiu" | "qiu" | "si";
  status: "pass" | "mixed" | "caution";
  reasons: string[];
}
```

保護條件：Direction `verdictFor()` 與 `rankDirections()` 不讀取 Day Gate。V1 的 `rankingUse` 維持 `disabled`，意思是「已顯示日課狀態，但尚不改八方排序」。

## 證據狀態與可核對來源

- [《多能鄙事》卷六〈旺相休囚死例〉](https://ctext.org/wiki.pl?chapter=582146&if=gb&remap=gb)：有頁影像入口與逐字表，直接支持五季定表。
- [《五行精紀》卷七](https://ctext.org/wiki.pl?chapter=728895&if=gb)：直接支持「當時、所生、所克、生我、克我」的關係算法及土旺四季十八日。
- [《御定星曆考原》卷一](https://ctext.org/wiki.pl?chapter=523984&if=gb)：直接支持四立前各十八日土旺。
- [《欽定續通志》卷九十八](https://ctext.org/wiki.pl?chapter=252230&if=en)：直接列出十二月建與各月節氣起點。
- [《造命宗鏡集》卷六數位本](https://www.shidianguji.com/zh/book/NA06432/chapter/1l0fx8tfgjc3v)：直接支持用日旺相、用時扶日、弱日可由時扶，以及沖破優先；本專案尚未保存固定版本原頁，因此 `primarySourceVerified` 仍標 `false`。

上述規則級對讀已可重跑；但《造命宗鏡集》的固定版本、頁碼與原頁影像尚未收入 repo，不能把 `primarySourceVerified` 寫成 `true`。
